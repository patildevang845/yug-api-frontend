# YUG-API front end (UI prototype)

Open `index.html` in a browser (Chrome recommended). No install, no server needed.

| File | Screen |
|---|---|
| Main.dc.html | Landing page (day/night toggle, parallax, animated demos) |
| Signup.dc.html | Onboarding: Select plan → Make payment → Start chatting |
| Home.dc.html | Workspace home |
| Inbox.dc.html | Team inbox |
| Campaigns.dc.html | Campaigns, templates, ads |
| Automations.dc.html | AI agents & automations |
| Analytics.dc.html | Analytics |
| Connect.dc.html | Channels & integrations |
| Components.dc.html | Buttons, states, motion reference |
| Motion.dc.html | Animated demo loops (GIFs in /assets) |

`support.js` is a small renderer that runs the pages; keep it next to them.
Placeholders to fill: [PRICE], [TOTAL]. Fonts load from Google Fonts (internet needed for the exact look).
